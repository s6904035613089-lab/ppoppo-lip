# ppoppo — Korean Lip Studio 💄 · ระบบ POS

เว็บไซต์หน้าร้าน + **ระบบขายหน้าร้าน (POS)** + หลังบ้าน สำหรับลิปแบรนด์ ppoppo
สร้างด้วย HTML + CSS + JavaScript + Bootstrap 5 (ไม่ต้อง build) · ฐานข้อมูล **Supabase** · ขึ้นเว็บด้วย **Vercel**

---

## แบรนด์

| หัวข้อ | รายละเอียด |
|---|---|
| ชื่อแบรนด์ | **ppoppo** (뽀뽀 = "จูบ" ในภาษาเกาหลี) |
| สโลแกนหลัก | **จูบแรกของริมฝีปากคุณ** |
| สโลแกนอังกฤษ | *Your lips' first kiss* |
| โทนสี | ชมพูคอรัล `#FF6B8A` · แดงเข้ม `#E8455F` · ครีม `#FFF7F2` · พีช `#FFB199` |

สินค้าตั้งต้น 12 เฉด (ทินท์ / ลิปสติก / กลอส / บาล์ม) ถูก seed ลงฐานข้อมูลให้แล้วใน `supabase/schema.sql`

## เริ่มใช้งาน 3 ขั้น

### 1. ตั้งค่า Supabase (ครั้งเดียว)
อ่าน **`supabase/README.md`** — สรุปคือ
1. รัน `supabase/schema.sql` ใน SQL Editor
2. เอา Project URL + anon key ใส่ `assets/js/config.js`
3. สร้างบัญชีพนักงานที่ Authentication → Users (บัญชีแรก = admin)

### 2. ลองรันในเครื่อง
ดับเบิลคลิกไม่ได้ (เบราว์เซอร์บล็อกสคริปต์จาก file://) ให้เปิดผ่านเซิร์ฟเวอร์เล็ก ๆ แทน

```
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```
แล้วเปิด http://localhost:8080 (หรือ `python -m http.server 8080` / Live Server ของ VS Code ก็ได้)

### 3. ขึ้นเว็บจริงด้วย Vercel (ฟรี)
**วิธี A — ไม่ต้องใช้ Git**
1. ไป https://vercel.com → Add New → Project → **Deploy without Git** (หรือลากโฟลเดอร์นี้ไปวาง)
2. Framework Preset = **Other** · ไม่ต้องใส่ Build Command
3. กด Deploy ได้เลย

**วิธี B — ต่อ GitHub (อัปเดตอัตโนมัติทุกครั้งที่ push)**
1. push โฟลเดอร์นี้ขึ้น GitHub
2. Vercel → Add New → Project → Import repo → Deploy

ไฟล์ `vercel.json` ตั้งค่า URL สวย (`/pos`, `/admin`, `/login`), security headers และ cache ให้แล้ว
ไฟล์ `.vercelignore` กันไม่ให้ `supabase/`, `tools/`, PDF และ .md ถูกอัปขึ้นเว็บสาธารณะ

> หลังขึ้นเว็บแล้ว ไปที่ Supabase → Authentication → URL Configuration
> ใส่โดเมน Vercel (เช่น `https://ppoppo.vercel.app`) ใน **Site URL** ด้วย

## หน้าต่าง ๆ

| URL | สำหรับ | ทำอะไร |
|---|---|---|
| `/` `index.html` | ลูกค้า | หน้าแรก, Shade Finder, สินค้าแนะนำ, ตะกร้า, สั่งซื้อออนไลน์ |
| `/products` | ลูกค้า | สินค้าทั้งหมด ค้นหา/กรอง/เรียง |
| `/login` | พนักงาน | เข้าสู่ระบบด้วยอีเมล + รหัสผ่าน (Supabase Auth) |
| `/pos` | แคชเชียร์ / แอดมิน | **หน้าขาย POS** |
| `/admin` | แอดมิน | หลังบ้าน |

### หน้าขาย POS (`pos.html`)
- แตะสินค้าจากกริด หรือพิมพ์รหัส / ยิงบาร์โค้ดแล้ว Enter
- ตะกร้าบิล: ปรับจำนวน, ส่วนลดรายชิ้น, โค้ดส่วนลด, ลดท้ายบิล
- ลูกค้า: ค้นจากเบอร์โทร → แสดงแต้ม / สมัครสมาชิกใหม่ทันที
- รับเงิน: เงินสด (คำนวณเงินทอน + ปุ่มลัด), พร้อมเพย์, โอน, บัตร
- ใบเสร็จ: แสดง + พิมพ์ (ขนาด 80 มม.) · ดูบิลวันนี้ / พิมพ์ซ้ำ / ยกเลิกบิล (คืนสต็อกอัตโนมัติ)
- กะ: เปิดกะด้วยเงินสดเริ่มต้น → ปิดกะแล้วระบบเทียบเงินสดที่ควรมีกับที่นับได้

### หลังบ้าน (`admin.html`)
- **ภาพรวม** ยอดวันนี้ กราฟ 14 วัน สินค้าขายดี ออเดอร์ออนไลน์รอยืนยัน สต็อกใกล้หมด
- **บิลขาย** กรองช่วงเวลา/สถานะ/ช่องทาง ค้นหา เปลี่ยนสถานะ ดูใบเสร็จ ดาวน์โหลด CSV
- **สินค้า** เพิ่ม/แก้/ลบ, บาร์โค้ด, ต้นทุน, อัปโหลดรูปขึ้น Supabase Storage
- **คลังสินค้า** รับเข้า / นับสต็อก / ของเสีย พร้อมประวัติทุกรายการ
- **ลูกค้า** สมาชิก แต้ม ยอดสะสม ประวัติซื้อ
- **โปรโมชัน** โค้ด % หรือบาท ขั้นต่ำ เพดาน ช่วงเวลา จำกัดครั้ง
- **กะ / ปิดยอด** ประวัติกะและส่วนต่างเงินสด
- **พนักงาน** เปลี่ยนสิทธิ์ admin / cashier เปิด-ปิดบัญชี
- **ตั้งค่า** ข้อมูลใบเสร็จ ค่าส่ง เกณฑ์เตือนสต็อก กติกาแต้ม

## การไหลของข้อมูล

```
ลูกค้าสั่งออนไลน์ ──► create_sale(channel=online) ──► sales(status=pending) ── ตัดสต็อก
                                                            │
แอดมินยืนยัน ─────► status=paid ──► สะสมแต้มลูกค้า           │
                                                            │
แคชเชียร์ขาย POS ──► create_sale(channel=pos, payments) ──► sales(status=paid) ── ตัดสต็อก ── สะสมแต้ม
                                                            │
ยกเลิก / คืนเงิน ──► status=cancelled|refunded ──► คืนสต็อกอัตโนมัติ (stock_movements type=return)
```

ทุกยอด (ราคา, ส่วนลด, ค่าส่ง, เงินทอน) คำนวณจริงในฐานข้อมูล — หน้าเว็บส่งแค่ `product_id` + จำนวน

## สิ่งที่ควรทำต่อถ้าจะใช้งานจริง

1. ต่อระบบชำระเงินออนไลน์จริง (Omise / GB Prime Pay / Stripe) ให้ออเดอร์ออนไลน์เปลี่ยนเป็น `paid` อัตโนมัติ
2. เปลี่ยนรูปสินค้า SVG เป็นรูปถ่ายจริง (อัปโหลดได้จากหลังบ้านเลย)
3. ต่อเครื่องพิมพ์ใบเสร็จความร้อน 80 มม. (หน้า POS รองรับ `window.print()` แล้ว)
4. เพิ่มรายงานเชิงลึก (กำไรต่อสินค้า มี view `v_product_sales` รอไว้แล้ว)
